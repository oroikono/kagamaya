# Project plan

1. Preserve the frozen v4 authority code and bind its development and untouched
   audit artifacts by exact SHA-256.
2. Add the score-max attack, fixed fine comparator, four-mode agreement control,
   producer-free replay, and sealed confirmation runner without opening IDs
   40--99.
3. Validate code, formulas, schemas, denominators, and exact v4 code identity;
   freeze v5 once.
4. Run one Euler source-preflight job that verifies the frozen source, upstream
   audit, data name, byte count, and full MD5 without opening confirmation rows.
5. Run exactly 60 array tasks. Task `i` may open only source ID `40+i` and must
   emit exactly 15 episodes and 180 selectable-view rows.
6. Aggregate only after all 60 tasks succeed. Require 900 unique episodes,
   10,800 selectable-view rows, 2,700 policy decisions, exact public-score and
   policy replay, and separate false-identification/false-omission counts.
