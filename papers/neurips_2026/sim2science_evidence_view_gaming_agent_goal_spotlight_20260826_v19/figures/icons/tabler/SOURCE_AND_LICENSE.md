# Icon source and license

The robot, lock, shield-check, circle-check, and refresh paths used in Figure 1
are adapted from the corresponding outline icons in **Tabler Icons**:

- Project: https://github.com/tabler/tabler-icons
- Source directory: `icons/outline/`
- License: MIT; the unmodified project license is vendored as `LICENSE`.
- Retrieval date: 2026-08-19.

The original SVG files are retained beside this note. The five tiny PDF assets
were extracted from TeX Live's `tablericons` 0.1.2 outline sheet, whose
documentation identifies Tabler Icons version 3.36.0 as its source. They are
vendored so the manuscript does not require that optional package at build
time. The numerical grid and all scientific math in the figure are original
diagram elements, not part of Tabler Icons.
