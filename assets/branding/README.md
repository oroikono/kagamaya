# Kagamaya emblem

The primary README image is a generated three-dimensional interpretation of
the project's mirror metaphor, selected on 8 October 2026. It uses frameless
glass and a small dark-wood base. The built-in image-generation tool edited
the preceding perspective concept; generated pixels and transparency are
preserved. The final edit prompt is bundled for provenance.

The flat alternatives are original, repository-native SVG drawings created
on the same date. No image-generation service was used for those SVG drawings
or their PNG exports. They are not copies of an anime character, an icon
library or a shrine artifact.

The uneven mirror carries an intact charcoal wave and an interrupted vermilion
reflection. This is a visual metaphor for information hidden by a numerical
representation, not a plot of measured data or a scientific certificate.
The altered reflection is intentionally impossible, not accurate mirror optics.

Palette: ivory `#F5F0E6`, charcoal `#292723`, vermilion `#AF493D`.

- `kagamaya-mark.svg`: editable symbol, transparent outside the ivory mirror.
- `kagamaya-lockup.svg`: editable emblem and serif wordmark on ivory.
- `kagamaya-mark.png`: 512-pixel rendered symbol for avatars/previews.
- `kagamaya-lockup.png`: 1560-pixel rendered alternative header.
- `kagamaya-perspective.png`: 1254-pixel transparent generated README image.
- `kagamaya-perspective-prompt.txt`: final image-generation edit prompt.

The wordmark uses local serif fonts with fallbacks; no font file is bundled.
PNG exports preserve the inspected rendering when a viewer substitutes fonts.
Existing repository licensing status is unchanged; this branding does not
grant rights to the paper, data, code or third-party assets.
