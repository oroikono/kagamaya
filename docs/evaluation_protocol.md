# Evaluation protocol

- Correct: exact in-library support identification, or library rejection for a deliberately omitted mechanism.
- False promotion: any other terminal conclusion.
- Inconclusive: no terminal conclusion.
- Coverage: terminal decisions divided by the explicitly stated denominator.
- Defense-aware search: enumerate all eligible four-mode groups and count conditions with at least one wrong common signature.
- Dependence: numerical implementations and related views are paired/shared-lineage, not independent replications.
