# Kagamaya workshop film

![Workshop film preview](../assets/video/workshop-film-thumbnail.png)

An animation-led explanation of the corrected workshop paper: the same
trajectory can lead to different verdicts when only the admitted numerical
summary changes. The edit leads with the score-free numerical failure, then
shows objective-conditioned choices and agreement versus fixed baselines.

Status: local author-voice draft, prepared for listening review. No YouTube URL
exists yet. The README preview links here rather than pretending to play a video.
Once an approved YouTube URL is available, its thumbnail can link directly there;
GitHub README does not use an arbitrary YouTube iframe.

The film uses already-generated, owner-consented Qwen3-TTS self-voice clips.
Hash and audio-format checks are not speech verification: the original automatic
transcription failed, and listening review is still required. External SRT/VTT
captions are not burned into the MP4; their timing is approximate, not forced
alignment. Upload the reviewed SRT track in YouTube Studio to enable toggleable CC.

Analytic fields and the toy sampling example are labelled illustrations, not
new benchmark results. The reported results are transcribed from the corrected
workshop manuscript. The positive PDEBench confirmation is not reproduced by
the historical code archive included here. The film is not a new experimental
result, main-track readiness claim, or scientific audit.

Only the thumbnail and these notes are included in the repository. The large
MP4, private voice reference, reference transcript, embeddings, and raw voice
clips are not bundled or uploaded. Repository visibility and release approvals
are unchanged.
